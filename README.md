# IEEE-RAG# 🏆 منصة BU-Shield: المرشد الأكاديمي الذكي لجامعة بيت لحم

نظام ويب سيبراني حاكم يعتمد تقنية الـ RAG ليكون بمثابة مرشد أكاديمي ذكي، يتيح لطلبة جامعة بيت لحم استرجاع اللوائح والخطط الدراسية بلهجتهم المحلية، مع حماية المخرجات من الهلوسة عبر التأريض الصارم للمستندات.

## 🛠️ الأدوات والنماذج المستخدمة (إفصاح الذكاء الاصطناعي)
- **لغة البرمجة:** Python لإدارة الخوارزمية الفنية.
- **واجهة الويب (UI):** مكتبة **Streamlit** (تصميم ملكي مظلم يدعم اتجاه RTL العربي).
- **أطر عمل الـ RAG:** استخدام **LangChain** و **LlamaIndex** لربط الأنابيب البرمجية.
- **الموديل اللغوي المحلي:** تشغيل نموذج **Llama3** عبر **Ollama** (محلي 100% لحماية خصوصية الجامعة).
- **نموذج الـ Embeddings:** نموذج **`multilingual-e5-large`** لفهم الفصحى واللهجات المحلية.
- **قاعدة البيانات المتجهة:** **ChromaDB** لتخزين البيانات الوصفية (اسم الملف ورقم الصفحة).

## ⚙️ معمارية الـ Backend وإستراتيجية التقطيع
- **حجم التقطيع (Chunk Size):** 512 Tokens مع تداخل (**Overlap**) بنسبة 10% لحفظ السياق.
- **إستراتيجية البحث:** بحث هجين (**Hybrid Search**) يدمج بين البحث النصي والدلالي.
- **حواجز الأمان (Guardrails):** حجب تلقائي (باللون الأحمر) لأي سؤال خارج النطاق لمنع التأليف.
- **التوثيق (Citation):** اقتباس آلي يذكر اسم المستند ورقم الصفحة بدقة.

## 📚 المصادر المغذاة المعتمدة (جامعة بيت لحم)
1. **خطة التمريض:** 139 ساعة معتمدة (كلية طارق الجفالي، صفحة 18).
2. **خطة تكنولوجيا المعلومات (IT):** 127 ساعة معتمدة (كلية العلوم، صفحة 5).
3. **خطة إدارة الأعمال:** 126 ساعة معتمدة (كلية شروق، صفحة 11).
4. **الأنظمة الأكاديمية:** قانون الحرمان عند غياب 15%، والعبء الدراسي للجدد (صفحة 14).
